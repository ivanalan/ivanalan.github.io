## Context

Tables built with auto layout commit to one axis. Restructuring a row-based table
into a column-based one means rebuilding it by hand and losing the frame
properties that were already set.

## What it does

Select a table with auto layout applied and the plugin switches it to the other
orientation, preserving frame properties and absolutely positioned children.
