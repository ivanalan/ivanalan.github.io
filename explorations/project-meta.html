01Chip row

Today's component, extended from two pairs to four. The control everything else is measured against.

In the header

Mid-page

Four pairs is where this starts to strain: the chips make every value look like a button, and a long role plus a long tools list wraps into a second line that no longer scans as a row. Reads better mid-page than in the header, where the chips compete with the title. Translation: flex flex-wrap gap-x-6 gap-y-2 text-sm with rounded-md border border-border bg-secondary px-1.5 py-0.5 on each value.

02Spec grid

Labels above values in equal columns, under a hairline rule. The standard editorial answer.

In the header

Mid-page

Fastest to scan of the eight, and long values wrap inside their own column instead of pushing the others around. The cost is that it looks like every other portfolio, and the rule plus four columns is a lot of structure for a solo project whose honest answer is "just me". Translation: grid grid-cols-2 gap-5 border-t border-border pt-4 sm:grid-cols-4.

03Hairline rows

Label left, value right, one rule per row. A spec sheet rather than a banner.

In the header

Mid-page

Survives any string length and any number of fields, and it is the only variant that would still work in a 10rem column. But four rules stacked in the header add visual weight right where the page should feel light, and the right-aligned values pull the eye away from the reading edge. Translation: grid grid-cols-[auto_1fr] border-t border-border text-sm with border-b border-border py-2 on every cell.

04Byline

One line, dot separated, labels only for screen readers. The lightest touch available.

In the header

Mid-page

Sits under the summary without asking for anything, which is exactly right for the header. It leans on the reader to infer which value is which: "Just me · 2025" is obvious, "Designer and developer" less so once the labels are visually gone. Translation: flex flex-wrap items-baseline gap-2 text-sm text-muted-foreground with sr-only on the dts.

05Panel

The same pairs grouped on a secondary surface, with the tools as brand chips.

In the header

Mid-page

The surface does the grouping so no rules are needed, and it is the one variant with room for the brand chips without them looking stranded. It also reads as a card in a layout that has none, and mid-page it competes with the figure directly above it. Translation: rounded-lg border border-border bg-secondary px-5 py-4 around a grid gap-4 sm:grid-cols-4.

06Sticky rail

A column beside the reading measure that follows the scroll, and collapses into the flow when there is no room.

In the header

Mid-page

Keeps the facts available for the whole scroll without spending a single line of the article on them. The problem is structural: the site's container is a single centred max-w-3xl column, so a rail either narrows the reading measure or has to break out of the container, and 10rem is not enough for "Designer and developer" to sit on one line. Translation: lg:grid lg:grid-cols-[minmax(0,1fr)_10rem] lg:gap-10 with lg:sticky lg:top-6 on the rail, and a container widened past max-w-3xl.

07Narrative sentence

The metadata written as prose, with brand chips inline. The move SiteIntro already makes on the home page.

In the header

Mid-page

The only variant that sounds like the rest of the site, and it turns "Just me" from a field into a claim. It cannot be skimmed, it has to be written by hand per project, and there is nowhere for a field to go if a project has a real team and a stakeholder list. Translation: a p at text-base text-foreground with BrandChip inline, exactly as in SiteIntro.astro.

08End credits

A serif heading over hairline rows, placed at the end of the case study instead of the start.

In the header

At the end, mid-page context

Puts the work first and the credentials after, which is the confident order and the one film titles use. It also means a reader who wants to know whether you did this alone has to scroll the whole case study to find out. The header column here is only for comparison; the point of this variant is the second demo. Translation: an h3 in font-heading over the same grid-cols-[auto_1fr] rows as variant 03, rendered after <Content /> in src/pages/work/[slug].astro.
